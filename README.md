## 🧠 Featured Projects

### ⚡ Harry Potter RAG Chatbot

A conversational chatbot using **Retrieval-Augmented Generation (RAG)** to answer questions about the Harry Potter books with strict grounding.

#### 🔥 Highlights
- Hybrid retrieval using **HyDE (Hypothetical Document Embeddings)**
- **FAISS vector search** on book chunks
- Strict grounding → no hallucinated answers
- Source citation per response
- Prompt caching to reduce API cost

#### 🛠️ Stack
- LLM: Claude Haiku
- Embeddings: HuggingFace (`all-mpnet-base-v2`)
- Vector DB: FAISS
- UI: Streamlit
